# 更新日志 (Changelog)

## [0.1.7] - 2026-08-01

### 🐛 终端联动与面板状态修复

- 修复终端 `cd` 联动失效：面板未加载时 reveal 消息丢失 → 增加暂存与面板就绪后补发；reveal 先于连接列表到达时自动重试。
- 修复联动展开后目录被面板刷新重置（改为按节点合并，保留展开/加载状态）。
- 修复路径尾斜杠差异导致逐级展开失败（统一 normalize 后匹配）。
- 滚动定位增加双保险（立即 + requestAnimationFrame）。
- 修复"未连接却可展开"的误导显示：浏览按需建连后自动刷新连接状态；断开连接时重置。
- `cd` 到不存在的目录时停止无意义重试。

## [0.1.6] - 2026-08-01

### ✨ 终端内置指令

- 新增斜杠内置指令（在扩展本地执行，不发送到远端 shell）：`/download`、`/download-dir`、`/upload`、`/upload-dir`、`/open`、`/cat`、`/tail`、`/mkdir`、`/rm`、`/mv`、`/ls`、`/pwd`、`/help`。
- 上传/下载按"远端相对 remotePath 的差值 → 工作区对应路径"映射；上传时本地文件不存在则跳过。
- 内置指令计入终端历史，操作结果实时刷新侧边面板。

## [0.1.5] - 2026-08-01

### 🎨 面板简化 + 终端联动

- 远程资源侧边面板简化为轻量版本（内嵌单文件，去掉虚拟滚动/右键菜单/自定义图标），操作改为行内悬停按钮。
- 新增终端 ↔ 面板联动：终端 `cd` 到某目录时，面板自动逐级展开并定位到该目录。

## [0.1.0] - 2026-08-01

### 🧩 从雷动三千工具集拆分

- 远程资源管理器（SFTP / SSH / FTP / FTPS）、远程终端从主扩展拆分为独立扩展。
- 命令 ID 与配置键沿用 `leidong-tools.sftp.*` / `leidong-tools.remoteTerminal.*`，`.vscode/sftp.json` 与设置无需迁移。
