# 更新日志 (Changelog)

## [0.1.22] - 2026-09-02

### 🛡️ 内置忽略 .git/.vscode + 新增忽略文件夹配置 + 下载回环修复

- **内置忽略 `.git`、`.svn`、`.hg`、`.vscode`、`.idea`**（任意层级）：这些目录的变更不再参与上传与自动上传监听——修复 Agent（如 Codex）工作期间 `.git/FETCH_HEAD`、`.git/refs/codex/...` checkpoint、`.vscode/settings.json` 被误传到远端服务器的问题（无需任何配置）。
- **新增配置 `remoteUploadExcludedFolders`**：排除指定文件夹——填文件夹名（如 `node_modules`，匹配任意层级同名文件夹）或工作区相对路径（如 `dist/cache`，从工作区根匹配）；与已有的 `remoteUploadExcludedExtensions`（文件后缀）、`remoteUploadExcludeRegex`（正则）叠加生效，对保存上传 / Agent 上传 / 文件夹上传 / Git 批量上传全部生效。
- **修复"下载/打开远端文件又触发自动上传"回环**：面板下载、当前文件下载覆盖、同步下载、终端 `/download` `/download-dir` `/open` 写入工作区后，监听器会在 15 秒窗口期内跳过这些文件，不再把刚下载的内容原样传回远端。
- **修复 `not a regular file` 报错**：外部修改监听只处理真实文件，目录/Agent 写盘中间态直接跳过，不再因 fastPut 失败反复断连重连。

## [0.1.21] - 2026-09-02

### 🧹 并发上传连接生命周期规划（防泄漏）

- **并发槽位连接按需建、用完即关**：文件夹/Git 批量上传的并发连接数量按 `min(并发配置, 文件数)` 扩缩，上传结束（含中途异常）后全部释放；不再长期占用服务器连接。
- **单文件/并发=1 不再额外建连**：直接复用主连接（与 Ctrl+S 保存上传、终端、浏览同一条），小批量传输零额外握手开销。
- **主连接始终保留**：批量上传的清理只释放 `profileId#uN` 槽位连接，不影响保存自动上传使用的主连接。
- **修复空闲超时误删主连接的 bug**：此前槽位连接空闲超时回调会按主连接 key 删除连接表（socket 未关闭造成主连接泄漏、面板状态错乱），现改为删除各自的连接 key。

## [0.1.20] - 2026-09-01

### 🐛 AI Agent 自动上传修复 + 独立开关

- **修复 Agent 修改文件不触发上传**：此前会跳过编辑器中 dirty（未保存）的文件，而 Codex 等 Agent 常以"编辑器挂起未保存 + bash 直接写盘"的方式改文件，恰好被此检查拦截——现移除 dirty 检查，只认磁盘内容；人工保存与监听上传由 2 秒去重窗口避免重复。
- **Agent 上传改为独立开关**：新增设置 `leidong-tools.remoteUploadOnAgentChanges` 与面板"⚡ Agent上传"按钮（命令 `leidong-tools.sftp.toggleAgentUpload`），不再与保存自动上传共用 `remoteUploadOnSaveEnabled` 字段，可单独开启/关闭（默认关闭）。
- 面板按钮更名："自动上传" → "⤒ 保存上传"，与"⚡ Agent上传"并列，职责一目了然。
- 开启 Agent 上传但当前工作区没有任何可用上传目标（sftp.json 中未开启 `uploadOnSave`）时，提示一次原因，不再静默无效果。

## [0.1.19] - 2026-09-02

### 🚀 并发上传加速 + 文件夹设置写入修复

- 新增 `leidong-tools.remoteUploadConcurrency`（并发上传连接数，默认 3，1-8，1 = 串行）：文件夹上传与 Git 变动批量上传按此并发数同时传输多个文件，每个并发槽位使用**独立连接**。
- 防冲突设计：上传前先**串行创建全部远端目录**（避免并发 mkdir 同一路径冲突），不同文件路径互不干扰；断开连接时会一并关闭所有并发槽位连接。
- **修复面板/命令切换"自动上传"报错**（不支持文件夹资源域，无法写入文件夹设置）：所有 `leidong-tools.remote*` 设置补充 `"scope": "resource"`，支持按工作区文件夹读写。
- 修正 `remoteUploadExcludeRegex` 声明类型为**数组**（与代码一致，支持多条排除正则；此前声明为 string 时单条正则会被按字符拆分导致过滤异常）。

## [0.1.18] - 2026-09-01

### ✨ AI Agent 修改文件自动上传

- 新增 `leidong-tools.remoteUploadOnAgentChanges`（**默认关闭**，需在设置中手动开启）：监听工作区磁盘变更，AI Agent（如 Claude Code 等直接写盘的 CLI Agent）或外部程序修改/新建文件后，防抖 500ms 自动按"保存自动上传"的目标配置上传到远程。
- 与保存自动上传共用一套目标与过滤规则（`uploadOnSave`、自动上传目标选择、扩展名/正则过滤），保存触发的上传会去重，不会重复传输。
- 编辑器内未保存（dirty）的改动不触发外部上传，仍以保存为准；文件删除不同步到远端。
- 远程资源面板工具栏改为**竖排一行一个按钮**，窄侧边栏下按钮文字不再折行。
- 提示：构建产物（如 dist/）也会被监听，可通过 `remoteUploadExcludeRegex` 排除。

## [0.1.17] - 2026-09-01

### 🐛 修复资源管理器右键上传丢失子路径

- **修复本地文件传到错误远端位置**：资源管理器右键「上传文件」此前固定传到 `remotePath` 根目录（`remotePath/文件名`），丢失了子目录层级；现在与编辑器右键、保存自动上传一致，按 `remotePath + 工作区相对子路径` 映射上传。
- 面板内对远程目录/连接节点的「上传文件/文件夹」语义不变（仍上传到该远端目录下）。

### ✨ 一键上传 Git 变动文件

- 新增命令"一键上传 Git 变动文件"（`leidong-tools.sftp.uploadGitChanges`）：读取当前工作区 Git 变动（暂存/未暂存/未跟踪新增），按 `remotePath` 映射批量上传到远程对应路径；已删除文件自动跳过并计数，命中上传过滤规则的文件跳过并提示。
- 远程终端新增内置指令 `/upgitchange`：同一套逻辑，按终端所属连接上传工作区 Git 变动，逐文件输出上传结果，执行期间状态栏显示同步进度。
- 远程资源面板工具栏新增"Git变动"按钮，一键触发上传。

## [0.1.16] - 2026-08-06

### 🧹 移除选择器提示 + 修复联动滚动

- 移除终端 `/` 指令提示与 `@` 文件选择器（内联列表与快速选择全部去掉），内置指令（`/download` `/upload` 等）直接回车执行，不再弹任何提示。
- **修复终端 cd 联动滚动定位的根因**：前端行节点的 `data-key` 此前恒为 `"undefined"`（节点数据无 `key` 字段导致选择器永远匹配不到元素），滚动代码从未执行——已改为按 nodeId/profileId+路径生成真实 key；滚动前确认容器可滚（布局完成），居中公式修正，成功即停止重试。

## [0.1.13] - 2026-08-01

### ⌨️ 终端内联选择器（Claude Code 式交互）

- `/` 与 `@` 选择器改为**终端内联候选列表**（渲染在输入行下方，不再弹模态弹窗）：
  - 输入 `/` 停顿 → 指令列表出现，继续输入即过滤，方向键选择，Tab/回车确认（无参指令直接执行、有参指令自动注入）

  - Esc 关闭且本次不再弹（再输入 `/` 或 `@` 恢复）；Ctrl+C 清行
- 选择器打开期间远端输出自动缓冲，关闭后统一输出，避免破坏列表渲染。
- 修复终端 cd 联动面板滚动：reveal 消息改为前端就绪后补发（此前 webview 未加载完成时消息丢失），滚动改为多段重试定位。

## [0.1.12] - 2026-08-01

### 🐛 内置指令输入可见性修复

- 修复内置指令（/help 等）执行后必须手动 Ctrl+C 的问题：内置指令模式的输入字符现在**本地回显**（之前缓冲不发送远端、远端不回显，输入在屏幕上不可见，看起来像卡住）。
- 支持内置指令输入中的退格擦除、Ctrl+C / Ctrl+U 清行；退出指令模式或回车补发时先清行，避免与远端回显重复。

## [0.1.11] - 2026-08-01

### 🐛 内置指令不再污染远端输入

- 修复内置指令执行后需要手动 Ctrl+C 的问题：指令模式的输入字符不再透传远端 shell，回车时统一决策（内置指令拦截执行、普通命令整行补发），远端输入行不再残留 `/help` 等脏字符。
