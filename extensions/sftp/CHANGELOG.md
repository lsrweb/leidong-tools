# 更新日志 (Changelog)

## [0.1.17] - 2026-09-01

### 🐛 修复资源管理器右键上传丢失子路径

- **修复本地文件传到错误远端位置**：资源管理器右键「上传文件」此前固定传到 `remotePath` 根目录（`remotePath/文件名`），丢失了子目录层级；现在与编辑器右键、保存自动上传一致，按 `remotePath + 工作区相对子路径` 映射上传。
- 面板内对远程目录/连接节点的「上传文件/文件夹」语义不变（仍上传到该远端目录下）。

### ✨ 一键上传 Git 变动文件

- 新增命令"一键上传 Git 变动文件"（`leidong-tools.sftp.uploadGitChanges`）：读取当前工作区 Git 变动（暂存/未暂存/未跟踪新增），按 `remotePath` 映射批量上传到远程对应路径；已删除文件自动跳过并计数，命中上传过滤规则的文件跳过并提示。
- 远程终端新增内置指令 `/upgitchange`：同一套逻辑，按终端所属连接上传工作区 Git 变动，逐文件输出上传结果，执行期间状态栏显示同步进度。
- 远程资源面板工具栏新增"Git变动"按钮，一键触发上传。

## [0.1.16] - 2026-08-06

### 🧹 移除选择器提示 + 修复联动滚动

- 移除终端 `/` 指令提示与 `@` 文件选择器（内联列表与快速选择全部去掉），内置指令（`/download` `/upload` 等）直接回车执行，不再弹任何提示。
- **修复终端 cd 联动滚动定位的根因**：前端行节点的 `data-key` 此前恒为 `"undefined"`（节点数据无 `key` 字段导致选择器永远匹配不到元素），滚动代码从未执行——已改为按 nodeId/profileId+路径生成真实 key；滚动前确认容器可滚（布局完成），居中公式修正，成功即停止重试。

## [0.1.14] - 2026-08-01

### 🛠️ 选择器与联动修复

- 文件选择器列表项宽度占满终端列宽（label 与 description 分栏），不再限制 44 字符。
- 本地文件候选上限 5000 → 20000，结果过多时列表末尾提示继续输入过滤。
- 终端 cd 联动增强：reveal 消息改为"尽力发送 + 有界缓存"，前端未就绪时不再丢失，错命令/异常后联动可恢复。
- 面板滚动定位改为 scrollIntoView 与手动 scrollTop 双保险，重试延长至 1.5s。
- 新增联动诊断日志：终端 cd 后面板定位成功/失败原因会写入"远程资源"输出面板，便于排查。

## [0.1.13] - 2026-08-01

### ⌨️ 终端内联选择器（Claude Code 式交互）

- `/` 与 `@` 选择器改为**终端内联候选列表**（渲染在输入行下方，不再弹模态弹窗）：
  - 输入 `/` 停顿 → 指令列表出现，继续输入即过滤，方向键选择，Tab/回车确认（无参指令直接执行、有参指令自动注入）
  - 输入 `/upload @`、`/download @` 等 → 文件列表出现（本地/远端按指令自动匹配），方向键选择，**Space 多选**（✓ 标记），Tab/回车批量执行
  - Esc 关闭且本次不再弹（再输入 `/` 或 `@` 恢复）；Ctrl+C 清行
- 选择器打开期间远端输出自动缓冲，关闭后统一输出，避免破坏列表渲染。
- 修复终端 cd 联动面板滚动：reveal 消息改为前端就绪后补发（此前 webview 未加载完成时消息丢失），滚动改为多段重试定位。

## [0.1.12] - 2026-08-01

### 🐛 内置指令输入可见性修复

- 修复内置指令（/help 等）执行后必须手动 Ctrl+C 的问题：内置指令模式的输入字符现在**本地回显**（之前缓冲不发送远端、远端不回显，输入在屏幕上不可见，看起来像卡住）。
- 支持内置指令输入中的退格擦除、Ctrl+C / Ctrl+U 清行；退出指令模式或回车补发时先清行，避免与远端回显重复。

## [0.1.11] - 2026-08-01

### 🐛 内置指令不再污染远端输入

- 修复内置指令执行后需要手动 Ctrl+C 的问题：指令模式的输入字符不再透传远端 shell，回车时统一决策（内置指令拦截执行、普通命令整行补发），远端输入行不再残留 `/help` 等脏字符。

## [0.1.10] - 2026-08-01

### ⌨️ 终端输入中实时选择器（参考 Claude Code 交互）

- 输入 `/`（或 `/命令前缀`）停顿片刻 → 弹出**内置指令选择器**：继续输入过滤、回车选择；无参数指令直接执行，需参数指令自动注入命令等待继续输入。
- 输入 `/upload @`、`/download @` 等 → 弹出**文件选择器**：选中即执行，支持多选批量（本地/远端按指令自动匹配）。
- 修复输入 `/` 触发幽灵路径提示的问题（内置指令模式不再走路径补全，Tab 可直接补全指令名）。
- 修复终端 cd 联动后面板无法滚动到目标目录（改为显式滚动容器 + 手动 scrollTop 计算，不再依赖 scrollIntoView）。

## [0.1.9] - 2026-08-01

### 🔗 连接保持与状态同步修复

- 连接空闲超时默认改为 **0 = 一直保持连接**；配置 `leidong-tools.remoteConnectionIdleTimeout` 单位改为**秒**，填非 0 值表示空闲指定秒数后断连。
- 修复断连后面板状态不更新：连接建立/断开（空闲超时、连接异常、手动断开）都会立即刷新侧边面板的"已连接/未连接"显示，与终端操作全流程保持一致。

## [0.1.8] - 2026-08-01

### ✨ 终端 @ 文件选择器

- 内置指令路径参数支持 `@` 前缀唤起文件选择器（输入过滤、多选）：
  - `/upload @` / `/upload-dir @`：选择工作区本地文件/目录上传
  - `/download @` / `/open @` / `/cat @` / `/tail @` / `/rm @`：选择远端文件操作
- `@` 后可带初始过滤词（如 `/upload @app/js`）。

## [0.1.7] - 2026-08-01

### 🐛 终端联动与面板状态修复

- 修复终端 `cd` 联动失效：面板未加载时 reveal 消息丢失 → 增加暂存与面板就绪后补发；reveal 先于连接列表到达时自动重试。
- 修复联动展开后目录被面板刷新重置（改为按节点合并，保留展开/加载状态）。
- 修复路径尾斜杠差异导致逐级展开失败（统一 normalize 后匹配）。
- 滚动定位增加双保险（立即 + requestAnimationFrame）。
- 修复"未连接却可展开"的误导显示：浏览按需建连后自动刷新连接状态；断开连接时重置。
- `cd` 到不存在的目录时停止无意义重试。

## [0.1.6] - 2026-08-01

### ✨ 终端内置指令

- 新增斜杠内置指令（在扩展本地执行，不发送到远端 shell）：`/download`、`/download-dir`、`/upload`、`/upload-dir`、`/open`、`/cat`、`/tail`、`/mkdir`、`/rm`、`/mv`、`/ls`、`/pwd`、`/help`。
- 上传/下载按"远端相对 remotePath 的差值 → 工作区对应路径"映射；上传时本地文件不存在则跳过。
- 内置指令计入终端历史，操作结果实时刷新侧边面板。

## [0.1.5] - 2026-08-01

### 🎨 面板简化 + 终端联动

- 远程资源侧边面板简化为轻量版本（内嵌单文件，去掉虚拟滚动/右键菜单/自定义图标），操作改为行内悬停按钮。
- 新增终端 ↔ 面板联动：终端 `cd` 到某目录时，面板自动逐级展开并定位到该目录。

## [0.1.0] - 2026-08-01

### 🧩 从雷动三千工具集拆分

- 命令 ID 与配置键沿用 `leidong-tools.sftp.*` / `leidong-tools.remoteTerminal.*`，`.vscode/sftp.json` 与设置无需迁移。
